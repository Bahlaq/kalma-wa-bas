# كلمة وبس

لعبة تخمين لاعبي كرة القدم (عربي، جهاز واحد، فريقان + حكم).

## Flutter app

المجلد [`app/`](app/) هو تطبيق Flutter الأصلي (أندرويد / iOS).

- البناء السحابي: [`codemagic.yaml`](codemagic.yaml)
- التفاصيل: [`app/README.md`](app/README.md)

```sh
cd app
flutter pub get
flutter test
```
